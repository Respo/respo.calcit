# Release 0.16.96 / 发布 0.16.96

- Publish the nominal `DomPatch` producer/consumer protocol from PR #142 for calcit-lang/calcit#828.
- Cover all 16 current DOM/effect variants with exhaustive matching and remove anonymous command construction from `respo.render.*`.
- Include positive and negative type gates, browser regression evidence, and unchanged keyed/lifecycle behavior.
- Upgrade Calcit and `@calcit/procs` to 0.14.0, js-ffi to 0.1.13, and Vite to 8.2.2; use Calcit's temporary compatibility mode until calcit-lang/calcit#902 is fixed.
- Fix SSR adoption so mount effects and refs collect the new single-value `DomPatch` without a callback arity failure.

- 发布 PR #142 为 calcit-lang/calcit#828 实现的名义 `DomPatch` 生产/消费协议。
- 通过穷尽匹配覆盖当前全部 16 个 DOM/effect variant，并删除 `respo.render.*` 中的匿名指令构造。
- 附带类型正反例、浏览器回归证据，并保持 keyed 与生命周期行为不变。
- Calcit 与 `@calcit/procs` 升至 0.14.0、js-ffi 升至 0.1.13、Vite 升至 8.2.2；在 calcit-lang/calcit#902 修复前暂用 Calcit 兼容模式。
- 修复 SSR adoption collector，使 mount effect/ref 能以单值 `DomPatch` 收集，避免回调 arity 错误。
