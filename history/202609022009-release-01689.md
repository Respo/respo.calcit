# Release 0.16.89

2026-09-02 20:09 CST

## English

- Upgrade the compiler and JavaScript runtime baseline to Calcit 0.13.75.
- Migrate strict state dispatch, effect callback returns, DOM host generics, and nullable DOM lookup boundaries discovered during downstream ecosystem validation.
- Publish the typed and total Node.js environment detection from PR #125.
- Keep `detect-nodejs?` Boolean when `process`, `process.release`, or `process.release.name` is absent, while narrowing the FFI value before homogeneous equality.

## 中文

- 将 compiler 与 JavaScript runtime 基线升级到 Calcit 0.13.75。
- 迁移下游生态验证中发现的严格状态 dispatch、effect callback 返回值、DOM host 泛型与可空 DOM 查询边界。
- 发布 PR #125 中类型化且保持全定义的 Node.js 环境检测。
- 当 `process`、`process.release` 或 `process.release.name` 缺失时，`detect-nodejs?` 仍返回 Boolean；执行同类型 equality 前先收窄 FFI 值。
