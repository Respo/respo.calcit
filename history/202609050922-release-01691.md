# 发布 0.16.91 / Release 0.16.91

## 中文

- 发布 Calcit 与 `@calcit/procs` 0.13.77 对齐，以及 `decorate-defcomp` 的显式 `Optional<Struct> -> Optional<Struct>` 更新回调类型修复。
- 发布全局键盘事件字段收窄，消除 Calcit 0.13.77 下的 `option:unwrap-or` 分支类型告警，同时保留合法键盘事件行为。
- 保持 Respo 的公开组件 API、渲染行为、DOM host fixtures 与质量基线门禁不变。

## English

- Release the Calcit and `@calcit/procs` 0.13.77 alignment together with the explicit `Optional<Struct> -> Optional<Struct>` update callback typing fix in `decorate-defcomp`.
- Release the global keyboard-event field narrowing that removes the Calcit 0.13.77 `option:unwrap-or` branch-type warnings while preserving valid keyboard-event behavior.
- Keep Respo's public component API, rendering behavior, DOM host fixtures, and quality baseline gates unchanged.
