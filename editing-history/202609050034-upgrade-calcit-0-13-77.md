# Upgrade Respo to Calcit 0.13.77 / 将 Respo 升级到 Calcit 0.13.77

## 中文

- 将 `deps.cirru` 与 `@calcit/procs` 从 0.13.75 对齐到 Calcit 0.13.77，并刷新 Yarn lockfile。
- 为 `decorate-defcomp` 中更新 `Component.tree` 的局部 callback 增加 `Optional<Struct> -> Optional<Struct>` 显式签名，保持现有运行逻辑不变并通过 0.13.77 类型检查。
- 将四个负向测试的错误捕获 ref 初始化为 String sentinel，并更新 README 的 `add-watch` 示例为双参数、Unit-return callback。
- 使用本分支作为本地 Respo module 验证 Recollect draft PR #48，0.13.77 `--check-only` 通过。
- 保持 Respo 0.16.90、DOM/rendering 行为、公开组件 API 和既有质量 baseline 不变。

## English

- Align `deps.cirru` and `@calcit/procs` from 0.13.75 to Calcit 0.13.77 and refresh the Yarn lockfile.
- Give the local `Component.tree` update callback in `decorate-defcomp` an explicit `Optional<Struct> -> Optional<Struct>` signature, preserving runtime behavior while satisfying the 0.13.77 type checker.
- Initialize error-capture refs in four negative tests with a String sentinel, and update README `add-watch` examples to two-argument, Unit-return callbacks.
- Validate Recollect draft PR #48 with this branch as its local Respo module; its 0.13.77 `--check-only` passes.
- Keep Respo 0.16.90, DOM/rendering behavior, public component APIs, and the existing quality baseline unchanged.
