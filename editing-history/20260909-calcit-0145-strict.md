# Calcit 0.14.5 strict migration / Calcit 0.14.5 严格类型迁移

- Upgraded the project, `@calcit/procs`, and `calcit-lang/js-ffi` to Calcit 0.14.5-compatible releases.
- Removed `--compat-types` from local scripts, documentation checks, tests, JavaScript generation, and CI.
- Migrated refs, effects, keyed children, cursor state, SSR, HTML serialization, and DOM host boundaries to explicit strict schemas.
- Replaced the generated `&list:append` compatibility path with the native typed `append` proc.
- Corrected zero-argument `%none` construction in tests and separated nullish JavaScript refs from Calcit `Option` values.
- Updated README and agent documentation examples so all checked snippets preprocess in strict mode.
- Refreshed the reviewed quality baseline after reducing `schemaDynamic` from 248 to 234, `unresolved` from 286 to 263, and `codeNil` from 42 to 34. Four new explicit `unsafeCoerce` sites isolate JavaScript/framework boundary conversions that were previously implicit.

- static quality baseline
- 58 Markdown files / 111 code blocks
- nominal DOM patch positive and negative checks
- typed DOM host and SSR ref contracts
